# Latino Mini Market

**Preview (live website):** [sysopx786.github.io/latino-mini-market](https://sysopx786.github.io/latino-mini-market/)

Hispanic, American, and Brazilian grocery, deli, and butcher on Bridge Street in Phoenixville, PA. SNAP / EBT welcome. Woman-owned.
